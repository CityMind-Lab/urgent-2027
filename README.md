# URGENT 2027

Website for the International Workshop on Agentic AI for Urban Data Science at IEEE ICDE 2027.

[Workshop website](https://www.citymind.top/urgent-2027/)

The site uses static HTML and CSS. GitHub Pages publishes from the root of `main`. Update `index.html` when the workshop schedule or the OpenReview venue link is ready.
